# Cozy Catch
Cozy Catch is a simple game i made where you're supposed to Control a basket move it around and catch fruits and leaves falling off a tree, there's also this evil squirrel trying to knock down as waste stuff so you have to watchout for it too, the games of a 6x6 diagonal grid(i know weird) but it looked unique and the main idea is you trying to catch and save as much stuff so the tree doesnt get discouraged and stop producing apples, This game was made for the Fall Game Jam 2026 by Myself(Huzaifa)

## Instructions
The Instructions are pretty simple, You can use the WASD keys or The arrow keys to move the bucket, it may seem hard at first but a word of advice imagine the grid top right side being the way ur facing when using the arrow or wasd keys.
W/arrow up= Forward
A/arrow left= Left
D/arrow right= Right
S/arrow back= Back
