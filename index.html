How I Made This

the idea for cozy catch came from wanting to make a cozy autumn arcade game about helping an old tree stay alive. i drew all the pixel art assets myself like the tree, bucket, apples, leaves, roots and squirrel and coded the game by hand

i also really loved this pixel font augie pixel from jame gam! it gave the game such a cool warm vibe so i used it for the whole ui and ill definitely be using it again in future projects
